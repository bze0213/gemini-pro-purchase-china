## 第一步：先接受一个事实，大陆个人账号不在官方支持范围

按 Google 的地区支持口径，中国大陆在清单里只对 Google Workspace 企业账号开放，普通个人账号不在列；香港也不在清单内，台湾和澳门在列。Gemini 按 IP 判定地区，所以大陆网络直接访问会提示地区不支持，而且订阅页只有美元等外币定价，没有人民币价。

这里有个很容易被忽略的坑：**付钱成功不等于权益能用**。V2EX 上有用户用银联卡订阅了 Google AI Pro，付是付过去了，但之后用 Gemini CLI 和 Antigravity 仍然触发地区限制。社区里讨论出的原因有两个层面——一个是账号 TOS 里的地区（Google 自己判定，跟 IP 有关，可以申诉改），另一个是付款资料的地区（这个好改，建资料时填哪里就是哪里，填美国免税州还能省税）。还有一点常被混淆：AI Pro 订阅和 API 调用是两套体系，订阅本身不给你 API 额度。

所以下单之前先想清楚：你要的是「订阅生效」，还是「订阅生效并且能在这台机器上用」。后者要麻烦得多。

## 官方那一档到底卖什么

用户口中的「Gemini Pro」，绝大多数指的是 **Google AI Pro 订阅**，不是某个单独的产品。Google 现在把消费端订阅拆成了多档（免费、Plus、Pro、Ultra），其中 Pro 档的官方定价是 **$19.99/月**，这一点在多个来源里是一致的。

Pro 档除了 Gemini 的高阶模型访问额度，还捆了一整套 Google 全家桶：Deep Research、NotebookLM 的更高用量、Gmail / Docs 里的 AI 集成、Jules 编程智能体，以及 Google One 云存储。存储额度官方调整过几次，看订阅页当前写的数字就行，别按老文章里的数值去买。

这个「捆一整套」是 Gemini 区别于 ChatGPT Plus 和 Claude Pro 的地方。如果你本来就在 Google 生态里——邮箱、文档、云盘都在用——那这笔账要整体算，不能只比月费。反过来，如果你只是想要一个聊天窗口，免费档已经能用到 Flash 系列的模型，Pro 的溢价不一定花得值。
